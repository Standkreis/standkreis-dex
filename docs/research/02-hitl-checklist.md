## 🚶 Field protocol

Pick **five subjects** on the walk and hit each one with apps 1–3 (plus Merlin for the bird, Pl@ntNet for the plants):

| Subject | Why |
|---|---|
| 🌳 A common tree (leaf + bark) | Baseline. Everyone should get this. |
| 🌼 A flowering plant, ideally something small or messy | Where plant AI actually differs. |
| 🐦 A bird you can *hear* but not clearly see | Merlin Sound ID vs everyone else's silence. |
| 🐝 An insect or spider | The hard case. Watch confidence vs correctness. |
| ❓ Something you genuinely don't know | The learning moment. Did you leave knowing more than the name? |

Score each app per subject, 1–5, on:

| Criterion | The question |
|---|---|
| ⏱️ Time to first answer | Seconds from open to species. Include retries. |
| 🎯 Believability | Did you trust it? Was it right, as far as you can tell? |
| 📚 Did I learn something | Beyond the name. |
| 🎴 Collection moment | Did adding it to the dex feel *good*? |
| 🔁 Tomorrow test | Would you open it again tomorrow for no reason? |

Also note, free-form: **the single most annoying moment** in each app.

Print or copy this table into your notes app:

```
App        | Subject | Time | Believe | Learn | Collect | Tomorrow | Most annoying
-----------|---------|------|---------|-------|---------|----------|---------------
Seek       | tree    |      |         |       |         |          |
```

## 🖥️ Desk pass (after the walk)

| Check | Apps | What to look for |
|---|---|---|
| **Onboarding** | all | How many screens before first ID? Account forced? Permissions asked up front? |
| **Collection / life list view** | Seek, Gotcha, BioSnap, iNaturalist, Merlin | Is it a grid, a list, a tree? Can you see *gaps* (what you haven't found)? Would you show it to a friend? |
| **"Nearby / plausible" list** | Seek, ObsIdentify, Merlin Explore | How is "what could I find here" presented? Seasonal? Silhouettes? |
| **Fix a wrong ID** | Merlin, Gotcha, Seek | Can you? How many taps? |
| **Export / backup** | all | Find the export button. Time yourself. Most have none. |
| **Pricing screens** | Gotcha, BioSnap, Birda | Where does the paywall appear? How honest is the trial copy? |
| **Species page depth** | Seek, Gotcha, iNaturalist, Pl@ntNet | Wikipedia stub or real content? Links out? Sounds? Range map? Similar species? |
| **Web** | iNaturalist, Pl@ntNet, Birda | What does the web version do that mobile doesn't, and vice versa? |

## 🔍 Claims from my analysis to double-check

These are the load-bearing conclusions. If your gut disagrees after using the apps, that outranks my sources.

| Claim | How to check |
|---|---|
| Seek's collection stalls and feels abandoned | Look at challenge dates, badge progression, last-update date in the store. |
| The dex games are shallow on nature but strong on the "collection moment" | Gotcha + BioSnap for 15 min each. Does the delight survive the second session? |
| The camera is not the hook; the collection is | After the walk: which app do you *want* to open to look at what you found? |
| Learning depth is a real gap | On the "something I don't know" subject, did any app teach you *why* it's that species? |
| Merlin is the ceiling for UX craft in this space | Compare its Sound ID and offline behaviour to everything else. |
| Nobody does web + mobile well | Try to see your Seek or Gotcha collection on a laptop. |
